# S3 이전 완료 기록

2026-10-28 사용자가 EC2의 로컬 파일을 S3로 이전 완료했다고 보고했다. 현재 운영 버킷은 서울 리전(`ap-northeast-2`)의 `grt-server`, 파일 prefix는 `grt/`이며 초기 관리 기준은 1TB다. 이 환경에서는 AWS 자격이 없어 운영 버킷을 직접 검사하지 않았다.

이전 도구는 로컬·S3 bytes의 크기와 SHA256을 비교한 뒤 DB의 파일 버전·저장 위치를 전환했다. 별도 백업은 만들지 않았고 로컬 원본은 남았다. 이전 완료 후에는 S3의 기록된 버전과 일치하는 로컬 복사본만 검증하여 정리한다. DB·설정·S3 원본은 이 정리 대상이 아니다.

완료된 버킷 생성·이전 실행 코드와 전용 검사는 현재 코드에서 제거했다. 과거 코드는 Git 이력에만 보존한다. 당시 최종 전환 스크립트는 [a286824](https://github.com/YeoJune/GRT_server/tree/a286824)에 있다. 이 문서는 이전 완료 기록이며 현재 실행 절차가 아니다. 현재 운영과 로컬 파일 정리는 [운영 문서](../operations.md)를 따른다.
