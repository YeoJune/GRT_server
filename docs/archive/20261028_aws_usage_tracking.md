# AWS 사용량 조회 철회 기록

AWS 비용 추적을 위해 Cost Explorer에서 계정 전체의 월별 표준 인터넷 전송량을 읽는 기능을 구현했으나 사용자의 요청으로 제거했다. API·화면·SDK·추가 IAM 설정 안내를 현재 코드와 문서에서 제거하고, 사용하지 않는 조회 캐시만 DB migration으로 정리한다. S3 저장 기능·저장공간 조회·큐 관리는 유지한다.

S3 직접 다운로드의 실제 전송량을 앱이 관찰할 수 없으므로 URL 발급량을 전송량으로 대체하지 않았다. 당시 구현과 안내는 [7de26c9](https://github.com/YeoJune/GRT_server/tree/7de26c9)에 보존한다. 이 기록은 현재 실행·설정 절차가 아니다.
